Thread pane density study

Six framings of the same Thread, at the pane's real width. Same content, same interactions — what changes is what leads and what stays folded. Round one asks what the pane should lead with; round two takes the notes-first answer and tries three ways of parking the Activity log. Everything is live: open the chevrons, switch the tabs, pull up the dock.

Shared across all three: one line system per pane instead of three, count badges become plain numerals, section hairlines dropped, Activity always folded.
